2 Introduction

3.2 Exposure, confounders and outcome

The exposure was RHC within the first 24 hours of ICU care, coded as a binary variable (1 = RHC; 0 = no RHC). Eleven baseline confounders were considered: age, sex, acute physiology score (APS), mean blood pressure, acute respiratory failure, congestive heart failure, chronic obstructive pulmonary disease, cirrhosis, coma, multiple organ system failure, and sepsis. The outcome was binary survival status (1 = survival, 0 = death).

3.3 Causal Estimand

The target estimand was the average treatment effect on the treated (ATT), defined as the difference in survival probability under RHC versus no RHC among patients who received RHC:

ATT = E[Y(1)-Y(0) | A=1]

where Y(1) and Y(0) denote potential outcomes with and without RHC, respectively, and A=1 indicates patients who actually received RHC.

3.4 Statistical Analysis

Propensity scores were estimated using logistic regression with eleven baseline covariates. Patients outside common support were excluded. Five ATT estimators were compared: propensity score adjustment, nearest-neighbour matching with and without replacement, IPTW, and AIPW. Covariate balance was assessed using standardised mean differences (|SMD| < 0.1). Treatment effects were expressed as survival risk differences, with 95% percentile confidence intervals estimated from 1,000 bootstrap replications.

4.3 ATT Estimates

ATT weighting, used in both IPTW and AIPW, achieved good covariate balance across all eleven covariates (|SMD| < 0.1). Nearest-neighbour matching with replacement also achieved adequate balance, whereas matching without replacement left four covariates imbalanced (mean blood pressure, APS, ARF, and sepsis). Four estimators suggested a modest reduction in survival associated with RHC (ATT: −0.0235 to −0.0307), with bootstrap confidence intervals excluding zero for propensity score adjustment, matching without replacement, and AIPW. However, matching with replacement yielded an ATT close to zero (−0.0046, 95% CI: −0.0485 to 0.0234). Overall, the results suggest a possible adverse effect of RHC on survival, although the magnitude and statistical significance varied across methods, and residual confounding cannot be excluded.

# Five ATT estimators
att <- function(d, save_matches = FALSE) {
  a <- d$treatment
  y <- d$survived
  w <- d$pscore / (1 - d$pscore)
  d1 <- subset(d, treatment == 1)
  d0 <- subset(d, treatment == 0)

  # 1. Adjustment for propensity scores
  fit1 <- glm(survived ~ pscore, data = d1, family = binomial())
  fit0 <- glm(survived ~ pscore, data = d0, family = binomial())
  adj_ps <- mean(predict(fit1, d1, type = "response") - predict(fit0, d1, type = "response")
  )

  # 2 & 3. Nearest-neighbour matching
  match_att <- function(replace) {
    m <- matchit(
      treatment ~ age + female + meanbp1 + aps1 + ARF + CHF + COPD + CIRR + coma + MOSF + sepsis,
      data = d,
      method = "nearest",
      distance = d$pscore,
      replace = replace,
      estimand = "ATT"
    )
    x <- match_data(m, data = d)
    list(
      ATT = with(x,
        weighted.mean(survived[treatment == 1], weights[treatment == 1]) -
        weighted.mean(survived[treatment == 0], weights[treatment == 0])
      ),
      model = m
    )
  }
  m_no <- match_att(FALSE)
  m_yes <- match_att(TRUE)

  # 4. IPTW
  iptw <- mean(y[a == 1]) - weighted.mean(y[a == 0], w[a == 0])

  # 5. AIPW
  outcome <- glm(
    survived ~ age + female + meanbp1 + aps1 + ARF + CHF + COPD + CIRR + coma + MOSF + sepsis,
    data = d0,
    family = binomial()
  )
  mu0 <- predict(outcome, d, type = "response")
  aipw <- mean(y[a == 1] - mu0[a == 1]) - sum(w[a == 0] * (y[a == 0] - mu0[a == 0])) / sum(a)

  estimates <- c(
    PS_Adjustment = adj_ps,
    Matching_no_replacement = m_no$ATT,
    Matching_with_replacement = m_yes$ATT,
    IPTW = iptw,
    AIPW = aipw
  )

  if (save_matches) {
    return(list(
      estimates = estimates,
      m_no = m_no$model,
      m_yes = m_yes$model
    ))
  }
  estimates
}
